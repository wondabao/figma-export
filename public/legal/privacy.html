隐私政策

Figma Export · 2026 年 11 月 26 日更新

本政策说明 wondabao 维护的 Figma Export 桌面工具如何处理账号、设计文件及任务记录，以及你可以如何管理这些数据。

登录与扫描

登录在内置的 Figma 页面中完成，凭据由 Figma 或你选择的身份提供方处理。工具在本机保存登录会话和账号缓存，用于识别当前用户并恢复登录状态。账号资料可包括用户标识、名称、邮箱及头像。

扫描时，工具会通过当前会话向 Figma 请求可访问的团队、项目、文件名称、标识和更新时间，以生成文件列表。你可以在导出设置中选择是否包含个人草稿。

导出与导入

导出时，文件从 Figma 下载至你选择的备份目录。该目录中的 export-manifest.json 记录文件名称、标识、所属项目、本机路径、更新时间和任务结果，用于识别重复备份及恢复目录结构。

选择文件或拖入目录时，工具在本机读取文件路径、名称和大小，生成导入队列。开始导入后，所选文件的内容会上传到 Figma 的目标位置，能访问导入文件的人员取决于该位置的共享权限。

本机记录与保留时间

应用设置目录保存账号缓存、备份路径和任务偏好，供下次启动使用。登录缓存保留至会话过期或你退出账号。活动日志在本次运行的内存中保留最近的任务记录，可能包含文件名、路径和错误信息。退出软件后，本次运行的内存日志会释放。

本地备份和清单由你管理，保留至你移走或删除。若备份路径属于共享文件夹或同步盘，该目录的权限和同步设置也会影响谁能访问文件。

更新检查与官网

软件启动或你点击“检查更新”时，会向 GitHub 请求项目的最新发布信息，并在本机比较版本号；选择在线更新时，会从 GitHub 下载对应系统的安装包至本机临时目录完成校验与重启替换。GitHub 可接收 IP 地址、请求时间及客户端请求头。该请求不包含设计文件、文件清单或 Figma 登录凭据。

点击“进入官网”或“前往下载”会使用系统浏览器访问相应网站。登录与云端文件操作由 Figma 提供，版本发布由 GitHub 提供，各服务按其自身隐私政策处理接收到的信息。

你的选择与联系

你可以在账号菜单选择“切换账号 / 退出登录”清除本机 Figma 登录会话和账号缓存，在文件管理器中查看、复制或删除备份与清单。已导入的云端文件可通过 Figma 管理。退出账号不会删除本地备份或云端文件。

如需了解数据处理情况，或提出查阅、更正、删除等请求，可联系官网公开邮箱 admin@yypic.com。来信时请说明所用功能和请求事项，并避免附上密码、登录凭据或设计源文件。
